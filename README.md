# 🌐 HTML5 Portfolio Project

Welcome to my **HTML5 Portfolio Practice Project**!  
This repository showcases my journey in learning **HTML5** by building a clean, semantic, and responsive personal portfolio website.

---

## 🚀 Overview

This project includes multiple HTML files that demonstrate:
- 🧱 **Semantic Structure** – Using `<header>`, `<nav>`, `<section>`, `<article>`, and `<footer>` effectively  
- 🎨 **Multimedia Integration** – Adding images, videos, and audio elements  
- 📱 **Responsive Layout** – Mobile-friendly design using flexible HTML5 techniques  
- 🔗 **Navigation System** – Smooth internal and external linking between pages  
- 💬 **Portfolio Dummy Content** – A realistic layout for personal or professional profiles
